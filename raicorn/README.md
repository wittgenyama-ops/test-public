## だいいちわ　あながわを あるく

あるひ、ちばけんの あながわに、ふしぎな いきものが あらわれました。
らいおんの かおに、あかい つの。おおきな しろい つばさと、くるんと まがった しっぽ。
なまえは「らいこーん」です。

らいこーんが ものれーるの えきの まえを のしのし あるくと、
おとなたちは「えええっ！？」「なにあれ！？」と びっくり。
でも、らんどせるを しょった こどもたちは「らいこーんだ！」と おおよろこびで かけよってきました。

ゆうがた、らいこーんは おおきな つばさを ひろげて、
ゆうやけの おおぞらへ とびたっていきました。

## だいにわ　ふみかちゃんと おともだち
