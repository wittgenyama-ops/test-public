# melumad2025pnasnexus: LLMとウェブ検索で学習の深さはどう違うか

> **確認レベル: fulltext**（2026-10-27）。PMC12560091 の全文を読んだ。補足資料（追試3件）は未読。

- **書誌**: Melumad, S., & Yun, J. H. (2025). PNAS Nexus, 4(10), pgaf316. doi:10.1093/pnasnexus/pgaf316
- プレプリント: SSRN 5104064。データと事前登録は OSF

## 方法と結果
すべての実験で、テーマを Google か LLM で調べた後、**別のページで**友人への助言を書く。

| 実験 | 設定 | 主な結果 |
|---|---|---|
| 1（事前登録, n=1,104） | 実際の Google と ChatGPT（GPT-3.5-turbo）、家庭菜園 | LLM群は検索時間が短い（743→585秒、クエリ数は2.15と2.06で同程度）。「新しいことを学んだ」3.86→3.43、知識の所有感 3.55→3.36。助言は短く（95→85語）、事実への言及が少なく（0.72→0.46）、助言同士の類似度が高い（コサイン 0.057→0.159） |
| 2（事前登録, n=1,979） | 模擬画面。**事実内容を同一にして**形式だけ変える（GPT-4o の要約か、それを6本の記事に書き分けたリンクか） | 同様の結果。助言の類似度は 0.072→0.224 |
| 3（実験室, n=250） | Google の AI Overview と通常の検索結果 | 同様の結果。助言は90→65語 |
| 4（事前登録, n=1,493） | 実験3の助言を盲検の受け手が評価 | LLM群の助言は役に立たない・情報が少ない・努力が少ない・信頼できない・勧めたくないと評価され、採用意向も低い |
| 補足の追試（n=2,402） | 健康的な生活。リンク付き LLM 要約の条件を追加 | リンク付きでも効果が残る。リンクをクリックしたのは**26%** |
| 補足の追試（n=1,976） | 詐欺被害への対処 | 同様の結果 |

- 実験1の構造方程式モデル: 検索の労力 → 知識の深さ（自己報告）→ 助言への関与と助言の豊かさ

## 限界（著者）
- 「助言を書く」という特定の課題。単に事実を調べる目的なら LLM が不利になる理由はない
- 深い事前知識が不要な話題での結果。専門的な領域では LLM の方が理解を助ける可能性がある
- **知識の深さは自己報告・助言文の特徴・受け手の評価で測っており、標準テストのような客観的な指標ではない**。そうした指標では LLM が有利な可能性もある
- Deep Research のような道具では、差がむしろ広がるかもしれない

## 批判的評価
- 効果は一貫して頑健だが、自己報告の差は5段階で0.1〜0.4点程度と大きくない
- 最も大きいのは**助言同士の類似度**（約3倍）。これは個人の能力より、集団レベルの均質化の証拠として重要（`doshi2024sciadv` と整合。一方 `stadler2024chb` では推奨の均質化は見られなかった）
- 本文中で総標本数が 10,462 と 10,426 の両方で書かれている。実験4の選択割合の記述は表記が不整合

## 本研究での位置づけ
- 「情報源を自分で探し、比べ、統合する」過程が、要約という形式によって省かれることの証拠
- **リンクを出しても26%しかクリックしない** → 検証の機会を与えても、検証は起きにくい
- 「知識が浅くなる」という主張の根拠は自己報告と産出物の特徴であることを、論文では明記する
