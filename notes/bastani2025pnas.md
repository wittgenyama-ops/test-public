## 方法
- トルコの大規模高校1校、2023–24年度の秋学期。9〜11年生の約50クラス、約1000名（優等クラスは除外）
- **クラス単位で無作為化**: 対照（教科書とノートのみ）／GPT Base（ChatGPT風）／GPT Tutor（教師が作った解答・よくある誤り・ヒントをプロンプトに含め、答えは教えない）
- 90分の授業 ×4回（学期の数学の約15%）: ①教師による復習 → ②演習（**ここだけ条件が異なる**） → ③教科書・PCなしの試験
- 試験の各問は、演習の問題と概念的にほぼ同じ
- 演習も試験も成績に入る。採点は独立した採点者が担当
- 分析: ITT、前年度GPA・セッション・採点者・学年・教師の固定効果、クラス単位のクラスター頑健標準誤差

## 結果（表1）
| | 演習（AIあり） | 試験（AIなし） |
|---|---|---|
| 対照群の平均（0〜1） | 0.284 | 0.321 |
| GPT Base | +0.137（+48%）** | **−0.054（−17%）*** |
| GPT Tutor | +0.361（+127%）** | −0.004（有意差なし） |

- **GPT Base の誤り**: 57問それぞれに「答えは？」と10回尋ねると、正答は51%。論理的誤り42%、計算誤り8%
- **「松葉杖」を示す2つの証拠**:
  1. GPT Base の論理的誤りは演習の成績を下げたが、対応する試験問題の成績には影響しなかった（誤りに惑わされたのではない）
  2. 生徒が得意なはずの計算の誤りも、論理的誤りと同程度に演習の成績を下げた → 解答を読まずに写している
- **関与**: GPT Base では、メッセージの多くが「問題文を貼る」か「答えを聞く」だった。GPT Tutor では回を重ねるごとに「自分の解答を示す」「助けを求める」が増えた
- **自己認識（重要）**: GPT Base 群は成績が下がったのに「成績が悪かった」「学びが少なかった」と感じていない。GPT Tutor 群は成績が上がっていないのに「よくできた」と感じていた
- **成績の散らばり**: AIは演習中に弱い生徒ほど助けて差を縮めたが、AIなしの試験ではこの縮小は消えた
- 事前登録された属性（能力・資源・努力）による効果の違いはほぼ見られなかった

## 著者による電卓との比較（考察）
> タイピングで手書きの必要が減り、電卓で計算の必要が減ったように、トレードオフ自体は新しくない。しかし ChatGPT は (1) 能力がはるかに広く知的で、(2) 信頼性が低く誤りが多い。生徒は誤りを見抜けないか、確かめる労力をかけようとしない。

## 限界
- 単一校・数学のみ・短期（同じ授業内の試験）。生成AIがまだ新しかった2023年秋の実施
- GPT Tutor は問題ごとに教師が解答とヒントを用意する必要があり、作るのに手間がかかる

## 本研究での位置づけ
- 「AI使用中の成績とAIなしの能力の乖離」の**最も強い証拠**（事前登録RCT、AIなしの客観的な試験）
- **メタ認知の錯覚**の証拠でもある: 学びが減ったことに本人が気づいていない
- 電卓との比較: 著者自身が「範囲の広さ」と「信頼性の低さ」を違いとして挙げている
